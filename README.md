# 无缝循环接缝查找器（Loop Seam Finder）

在浏览器本地分析音频，为循环区间自动搜索平滑接缝点的 Web 工具。
技术栈：React + TypeScript + Web Audio API，**音频不会上传，全部在本地处理**。

## 一键启动（Docker）

```bash
docker compose up --build
```

启动后访问：**http://localhost:8080**（容器内端口 80，映射到宿主机 **8080**）。

停止：`docker compose down`。

## 本地开发

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 产物输出到 dist/
npm run preview    # 预览构建产物
```

## 使用流程

1. **导入音频**：点击或拖入 WAV / MP3 文件，浏览器本地解码并显示波形。
2. **框选区间**：在波形上拖拽框选大致的循环区间；橙色边界把手可拖动微调。
3. **查找候选接缝**：点击「查找候选接缝」，系统会在两个边界 ±搜索半径 内枚举候选采样点，
   以「幅值差 + 短窗斜率差」（按信号 RMS 归一化、全声道求和）为代价函数，
   经粗网格 + 逐采样点两级搜索找出**代价最低的 5 个接缝**；
   起止点均相距不足 10 ms 的结果会被去重，避免同一局部极小值占满列表。
   候选按代价升序排列，波形上以绿色编号徽标同步标出（高亮为当前选中）。
4. **点选候选试听**：点击候选列表中的任意一行即循环试听该候选（再点一次停止），
   当前选中项即为导出目标；「试听原区间」可随时 A/B 对比，
   优化区间按设定的交叉淡化时长做等功率淡化。
5. **微调参数**：搜索半径（5–500 ms）与交叉淡化时长（0–500 ms）均可调；
   修改淡化时长会在播放中实时生效；**调整选区或搜索半径会清空候选并禁用导出**，需重新查找。
6. **接缝频谱检查**：选中候选后，面板对「实际播放/导出的循环缓冲」（含交叉淡化）的
   循环头部与尾部各取相同长度片段，按 50% 重叠 Hann 窗执行 STFT，将对应时间帧在
   **8 个对数频带**上的能量差（dB）绘成可缩放热图（滚轮缩放、拖拽平移、双击复位、
   悬停查看各帧 dB 数值），并汇总**最大差值**（含帧/频带定位）与**最差频带**（平均差值最大）。
   切换候选、调整交叉淡化或检查窗均实时重算；检查窗可在 **50–500 ms** 间选择，
   窗长超过循环一半时自动夹取并在面板中提示；静音频带以 −120 dBFS 地板兜底，
   任何结果都不会出现 NaN/Infinity。
7. **导出**：「下载 JSON」获得选中候选的起止时间、全部候选列表、搜索参数与频谱诊断
   （检查窗/FFT/频带参数、逐带最大/平均差值、最大差值定位及完整逐帧差值矩阵）；
   「下载 WAV」导出选中候选的循环音频（16-bit PCM，含 smpl 循环区块）。

## 导出 JSON 字段

| 字段 | 说明 |
| --- | --- |
| `file` / `sampleRate` / `channels` / `durationSec` | 源文件信息与音频格式 |
| `original` | 用户粗选区间（秒与采样点） |
| `optimized` | 当前选中候选的循环起止点（秒与采样点） |
| `loopDurationSec` | 优化后循环时长 |
| `candidates` | 全部候选接缝列表（按代价升序，含起止点与代价） |
| `selectedCandidate` | 导出目标对应的候选编号（从 1 开始） |
| `parameters` | 搜索半径、交叉淡化时长、斜率窗口等参数 |
| `seamCost` | 选中候选的归一化接缝代价（越小越平滑） |
| `spectrumDiagnostics` | 接缝频谱诊断：`parameters`（实际/请求检查窗、是否夹取、FFT 点数、hop、Hann/50% 重叠、频带数、能量地板）、`bands`（8 个频带的实际 Hz 范围与逐带最大/平均差 dB）、`result`（最大差值及帧/频带编号、最差频带）与 `diffMatrixDb`（[帧][频带] 差值矩阵，与热图一致） |

## 算法说明

- **接缝代价**：`Σ声道 (|x[s] − x[e−1]| / RMS幅值 + w·|前向斜率(s) − 后向斜率(e)| / RMS斜率)`，
  斜率取接缝两侧各 32 个采样点的短窗平均变化率。
- **候选去重**：粗网格命中按代价升序贪心筛选，起止点均相距不足 10 ms 的命中
  视为同一局部极小值被跳过；逐采样点细化后再次去重，保证候选列表覆盖不同的低谷。
- **交叉淡化**：循环尾部 N 个采样点与头部 N 个采样点做等功率（sin/cos）淡化，
  循环体整体前移 N 个采样点，保证回绕处连续无爆音。
- **接缝频谱检查**：对播放/导出同一份循环缓冲（即含交叉淡化）取头部、尾部各 W 个采样点
  （W 由 50–500 ms 检查窗换算，超过循环一半则夹到 ⌊L/2⌋）；FFT 长度取 ≤ W/4 的最大 2 的幂
  （上限 2048，短窗时回退 ≤ W/2，保证至少 1 帧），hop = FFT/2，加周期 Hann 窗
  `w[n] = 0.5(1 − cos(2πn/N))`；单边幅度谱按 1/N² 归一化、多声道取平均，
  8 个几何等距（对数）频带从 max(20 Hz, 1 仓宽) 覆盖到 Nyquist，能量积分后转 dBFS，
  功率下限 −120 dBFS（静音段安全兜底）。热图为 |尾部 dB − 头部 dB|，逐帧逐带对齐。
